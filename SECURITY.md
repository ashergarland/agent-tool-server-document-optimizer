# Security

Report vulnerabilities privately through GitHub Security Advisories for this repository. Do not
open a public issue for an undisclosed vulnerability.

The default profile is local and read-only and requires no secrets. A capability that adds hosted,
provider-backed, or mutating support must declare that profile truthfully, keep secret values in an
external secret store, keep operator state in private Git, use least privilege, and preserve the
shared security workflow gates.
